# Data Analysis - Marketing and Sale domain
End-to-end Data analysis and BI project.

This analysis is built on a public dataset related to customers' journey and social media behaviour from a sportswear company.
# Skills and Tools
Python

SQL

Power BI
# Project structure
1. Define key metrics
2. Clean data using SQL
3. Analyse advanced sentiment score with Python
4. Present data with Power BI dashboards
